# 🤝 Contributing to ModelLens

Thanks for your interest in contributing to **ModelLens**.

## 🛠️ Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Test your changes locally.
6. Open a pull request.

```bash
git clone https://github.com/ATLURI0001/ModelLens.git
cd ModelLens

git checkout -b feature/your-feature
```

## 📌 Pull Requests

Please make sure your pull request:

- Clearly describes the change.
- Includes relevant tests when applicable.
- Does not introduce unnecessary dependencies.
- Keeps the existing project structure and coding conventions.
- Updates documentation when necessary.

## 🐛 Bug Reports

When reporting a bug, include:

- What happened.
- What you expected to happen.
- Steps to reproduce the issue.
- Relevant logs or error messages.
- Environment details when useful.

## 💡 Feature Requests

Describe the problem your feature solves and explain how you expect it to work.

## 📜 Code of Conduct

Please keep discussions respectful, constructive, and focused on improving the project.

Thank you for contributing to ModelLens. 🔍
