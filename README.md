# 🔍 ModelLens

> **Inspect what's happening inside models.**

ModelLens is an AI observability platform for **LLMs and AI agents**. Trace model interactions, monitor performance, analyze costs, and evaluate AI outputs from a single platform.

## ✨ Features

- 🔍 LLM & agent tracing
- 🧠 Prompt and response tracking
- 📊 Token usage & cost analytics
- ⚡ Latency and performance monitoring
- 🛠️ Tool and agent execution tracking
- 🧪 Model evaluation
- 📈 AI application dashboards

## 🚀 Getting Started

```bash
git clone https://github.com/ATLURI0001/ModelLens.git
cd ModelLens
```

Install dependencies and start the development server according to the project setup.
